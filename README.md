# Laboratorio 9: Taller de regresion e interpolacion

Este repositorio contiene el desarrollo del Laboratorio 9 de Metodos Numericos.

## Archivo principal

- [Taller_Regresion_Interpolacion.ipynb](Taller_Regresion_Interpolacion.ipynb)

## Contenido

- Regresion lineal, cuadratica y exponencial.
- Ajuste potencial y analisis de residuos.
- Interpolacion directa, Lagrange y diferencias divididas de Newton.
- Comparacion numerica, graficas y conclusiones.

## Ejecucion

Abra el notebook con Jupyter Notebook o JupyterLab y use un kernel de Python con NumPy, pandas, Matplotlib y SciPy.
